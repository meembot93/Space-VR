# Textures

Real-surface photos for js/surfaces.js. All CC0 (public domain): free to use in any game, no credit needed.
Taken from Poly Haven (polyhaven.com) and ambientCG (ambientcg.com), via the zuujis-cc0 GitHub mirror.

Each is shrunk to 1024 px (detail, `_d.jpg`: the colour divided by its own blur, so it only adds detail
to the game's colours) and 512 px (normal map, `_n.jpg`, OpenGL style). Made with a small Python script
(colour / blurred colour, per-channel mean 0.5).
